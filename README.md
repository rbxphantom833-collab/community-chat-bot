# Community Chat Bot

A simple Discord.js v14 community bot with friendly/funny chat replies, basic utility commands, and welcome-message settings.

## Run
1. Install Node.js 20 or newer.
2. Copy `.env.example` to `.env`.
3. Put your **newly reset** Discord bot token in `.env` as `DISCORD_TOKEN`.
4. Run `npm install` then `npm start`.

## Railway
Set `DISCORD_TOKEN` in the Railway service Variables. Never commit `.env` or share your token in chat.

## Discord Developer Portal
Enable the **Message Content Intent** and **Server Members Intent** if you want chat replies and welcome messages.
